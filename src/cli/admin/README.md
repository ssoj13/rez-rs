# cli/admin/

Commands for system administration, diagnostics, embedded Python access, and tooling.
These commands do not modify packages but provide configuration introspection,
system health checks, and developer utilities.

## Files

| File | Description |
|------|-------------|
| mod.rs | Module declarations for all seven admin commands. |
| config.rs | `rez config` -- Query and display configuration settings. Supports dot-notation field queries, `--json` output, `--search-list` (searched config paths), and `--source-list` (actually loaded config files). |
| status.rs | `rez status` -- Show rez system status: version, platform, arch, OS, shell, user, hostname, config paths, packages paths. |
| selftest.rs | `rez selftest` -- Run the project's test suite via `cargo test --workspace`. Convenience wrapper for CI and self-validation. |
| benchmark.rs | `rez benchmark` -- Resolve benchmarking suite. Runs multiple resolves with timing, histogram output, and comparison between runs. |
| memcache.rs | `rez memcache` -- Manage memcache servers used for resolve caching. Subcommands: flush, stats, poll, warm. |
| python.rs | `rez python` -- Embedded RustPython interpreter. Three modes: interactive REPL (no args), execute code string (`-c CODE`), run script file (positional arg). |
| forward.rs | `rez forward` -- Execute a YAML forwarding script. Hidden command used internally by suite wrapper scripts to load a context and run a tool within it. |

## Architecture

Most admin commands are thin wrappers around library functionality:

```
rez config FIELD    -> CONFIG.get_field(field) -> print
rez status          -> Status::collect() -> print formatted
rez selftest        -> std::process::Command::new("cargo").args(["test", "--workspace"])
rez python          -> same-executable re-entry -> python_runtime -> native RustPython CLI
rez benchmark       -> loop { Resolver::resolve(requests) } + timing stats
```

The `forward` command is special -- it is never invoked directly by users.
Suite wrapper scripts (generated by `rez suite`) call `rez forward` with a
YAML file path that specifies which context to load and which tool to execute.

The `python` command delegates to the embedded RustPython 0.6.0 VM, which runs
on a dedicated 8MB stack thread to avoid stack overflow during stdlib imports.

## Key Types Used

- `model::config::CONFIG` -- global configuration singleton
- `resolve::status::Status` -- system status snapshot
- `python_runtime` -- embedded interpreter and native Python CLI execution
- `resolve::python_vm` -- Python execution adapter with context bindings for resolved environments
- `resolve::resolver::Resolver` -- used by benchmark

## Usage from main.rs

```rust
Commands::Config(ref args) => cli::admin::config::run(args),
Commands::Status(ref args) => cli::admin::status::run(args),
Commands::Selftest(ref args) => cli::admin::selftest::run(args),
Commands::Python(ref args) => cli::admin::python::run(args),
// ...
```
